# DayBuoy Round 2

Five new expanded sheets: Sun (40% height), Water, Waves, Wind, Sky/Air (55%). No old panels/tabs are used. Thick glass chart tracks all control the global forecast time and shared sun. Day selection, keyboard time changes, skin/SPF preferences, a local tanning timer, and drag-to-close are supported.

Scene changes use existing time-driven wave, tide, cloud and weather uniforms. Added scene-space flat wind compass/arrow, a bending flag, and a buoy-relative wave ruler. Wave/ocean surface implementation is unchanged.

Custom weather glyphs are hand-authored SVG. All screenshots use actual WebGL rendering with software Chromium at 390×844. Review data is explicitly illustrative. The review-only visibility, rip-risk and set-count labels reproduce the reference; normal forecast mode shows unavailable states where the retained providers supply no measurement. SPF does not extend the burn estimate.
